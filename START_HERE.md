# EMPIECE AQUÍ

Este archivo existe para evitar el error más frecuente: abrir codex y pedir «hazme una malla curricular».

No haga eso.

El producto final debe cubrir, como mínimo:

- malla curricular moderna, accesible, responsive e interactiva;
- auditoría de avance por componente, agrupación y requisito;
- historia académica y múltiples intentos;
- equivalencias, homologaciones, sustituciones y excepciones;
- prerrequisitos, correquisitos y requisitos compuestos;
- requisitos por créditos, porcentaje, componente y agrupación;
- requisitos no crediticios de grado;
- grafo de dependencias directo y transitivo;
- explicación de «qué abre» y «qué me bloquea»;
- ofertas por período, secciones, horarios y conflictos;
- planificador de semestres con escenarios;
- optimizador de trayectoria con restricciones y preferencias;
- versionado temporal de currículos y normas;
- procedencia de cada regla y vínculo a evidencia;
- flujo de ingestión → extracción → revisión → publicación;
- backoffice curricular;
- multiinstitución/multisede/multiprograma desde el modelo de dominio;
- roles, permisos y auditoría;
- importación de historia académica;
- analítica estudiantil e institucional;
- observabilidad, seguridad, backups, recuperación y despliegue;
- pruebas unitarias, de propiedades, integración, contrato, accesibilidad y E2E;
- actualización segura de dependencias y documentación;
- memoria de agente persistente y recuperación entre sesiones.

**No se acepta una entrega que resuelva únicamente una parte de lo anterior y se autodenomine producto terminado.**

Lea `AGENTS.md`, luego `docs/00_PRODUCT_SCOPE.md`, luego el prompt maestro.
