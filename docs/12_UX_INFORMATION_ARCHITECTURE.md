## Dashboard estudiante

Above the fold:
- avance total;
- componente con mayor deuda;
- próximos desbloqueos;
- cursos elegibles;
- alertas de requisitos;
- escenario activo.

No presentar un «% graduado» engañoso calculado sólo por créditos.

## Malla principal

Desktop:
- columnas por layout;
- tarjetas compactas;
- sticky encabezados;
- panel lateral de detalle;
- enfoque contextual.

Mobile:
- lista/roadmap vertical;
- filtros;
- drawer de detalle;
- no miniaturizar 9 columnas.

## Estados visuales

Usar icono + texto/tooltip + patrón/outline; color sólo como señal redundante.

## Panel curso

- metadata;
- estado;
- cuenta para;
- requisito para cursarlo;
- requisito exacto no satisfecho;
- desbloqueos directos;
- desbloqueos indirectos;
- oferta;
- evidencia;
- acciones: agregar a escenario, comparar, abrir grafo.

## Accesibilidad

WCAG 2.2 AA:
- navegación completa por teclado;
- focus visible;
- ARIA correcto;
- contraste;
- reduced motion;
- zoom 200%;
- nombres accesibles para nodos/aristas;
- alternativa textual para grafos.
