# 27 — Internacionalización

Idioma inicial: español.

No hardcodear textos dentro del motor. El dominio emite códigos y datos.

Preparar:
- message catalogs en `apps/web/lib/i18n/messages.ts` (`es-CO` inicial y
  catálogo `en` preparado);
- nombres oficiales preservados en idioma fuente;
- timezone por campus;
- decimal/date locale;
- traducción de UI separada de evidencia normativa.

Los componentes del shell consumen claves del catálogo mediante `translate` o
`messages`; la selección de locale queda separada de la resolución de reglas.
Los datos oficiales (nombres de cursos, normas y evidencia) entrarán como datos
del backend y no se traducirán silenciosamente desde la interfaz.

La evidencia nunca se «traduce» sustituyendo la fuente original; puede acompañarse de traducción informativa.
