# 38 — Búsqueda, filtros y orden

## Cursos
Buscar por código/nombre; filtrar por componente, agrupación, créditos, estado personal, elegibilidad, oferta, período y requisito.

## Malla
Filtros no destruyen contexto: permiten ocultar/atenuar, con botón de reset y estado en URL cuando tenga valor compartible.

## Admin
Filtros por institución/sede/programa/plan/revisión/estado epistemológico/fuente/fecha/reviewer.

## Orden estable
Todo endpoint paginado usa orden determinista y cursor o paginación documentada. Nunca depender del orden accidental de DB.
