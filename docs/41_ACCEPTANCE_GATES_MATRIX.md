# 41 — Matriz de gates de aceptación

| Área | Gate mínimo para producción |
|---|---|
| Currículo | invariantes + evidencia + review + revisión inmutable |
| Motor reglas | unit + property + golden cases |
| Auditoría | no doble conteo + explicación + snapshots reproducibles |
| Seguridad | threat review + authz tests + secret scan + dependency scan |
| API | OpenAPI válido + cliente generado + contract tests |
| Frontend | unit/component + E2E + axe + responsive |
| Importaciones | idempotencia + validación + quarantine de errores |
| Optimización | feasibility tests + timeout + explicación de no-solución |
| Operación | métricas/logs/traces + alertas + runbooks |
| Datos | backup/restore probado + políticas de retención |
| Deploy | rollback + smoke test + health/readiness |

Ningún gate se satisface sólo porque el agente diga que «se ve bien».
