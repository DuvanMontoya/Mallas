# Criterios de aceptación del dominio

- 112/141 no satisface 80%; 113/141 sí.
- aprobar un curso no garantiza que todos sus créditos se apliquen a cualquier agrupación.
- una condición `ANY(A,B)` se satisface con A o B, no exige ambos.
- una condición `ALL(A,B)` exige ambos.
- `UNKNOWN` produce resultado explicable y no se silencia.
- un correquisito se distingue de un prerrequisito.
- Práctica Estudiantil 2028081 sólo resulta elegible cuando el Núcleo Estadístico está completado según la revisión.
- Diseño y Desarrollo de Encuestas valida simultáneamente Muestreo y el umbral de Programación.
- publicación de una revisión no permite mutación posterior.
