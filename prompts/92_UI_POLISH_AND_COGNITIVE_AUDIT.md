# Auditoría UX/UI de calidad editorial

No cambies reglas de dominio.

1. Ejecuta la app real con datos fixture representativos.
2. Recorre dashboard, malla, grafo, auditoría, oferta, planner y backoffice.
3. Evalúa jerarquía, densidad, legibilidad, consistencia, responsive y empty/error/unknown.
4. Elimina ruido visual, no información útil.
5. Verifica que el usuario entienda diferencia entre aprobado/elegible/ofertado/planeado/bloqueado.
6. Comprueba que cada bloqueo responda «por qué».
7. Comprueba que «qué abre» sea comprensible.
8. Keyboard, screen reader, 200% zoom, reduced motion.
9. Optimiza microcopy español.
10. No uses color como único estado.
11. Ejecuta ux-reviewer y Playwright/axe.
