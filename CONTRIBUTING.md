# Contributing

Toda contribución debe:
- corresponder a un item de roadmap o issue;
- respetar AGENTS.md;
- incluir tests;
- mantener el motor académico determinista;
- evitar reglas académicas hardcoded en UI;
- incluir evidencia en cualquier cambio curricular;
- actualizar ADR/docs cuando cambie comportamiento;
- pasar `python scripts/verify.py`.

Commits recomendados: Conventional Commits.
No se aprueba PR con verificaciones rojas ni con hallazgos Critical/High sin resolver.
